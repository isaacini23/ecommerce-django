# Django E-commerce Practice Project

This repository contains an earlier Django e-commerce project.

It is separate from the more recently developed [Django E-commerce Platform](https://github.com/isaacini23/ecommerce), which is the preferred repository to review for the current e-commerce work.

## Project Information

- **Framework:** Django
- **Project configuration module:** `last2` (see `manage.py`)
- **Purpose:** E-commerce application development and practice

## Status

This repository is retained as an earlier development project. Its current dependencies, database configuration and feature completeness have not been verified in this README update. Do not assume it is production-ready.

## Getting Started

The repository does not currently include a verified dependency manifest at its root. Before running it, inspect the Django settings, install compatible dependencies in a virtual environment, configure the database and apply migrations.

Typical Django commands, once the environment is configured:

```bash
python manage.py migrate
python manage.py runserver
```
